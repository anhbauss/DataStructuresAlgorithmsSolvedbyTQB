# Cách làm bài toán tháp Hà Nội bằng đệ quy:
## Tổng quát:
  + Chuyển n-1 đĩa trên cùng từ A sang C --->(1): Cột hiện tại: A, Cột đích: C, Cột trung gian: B
  + Chuyển đĩa thứ n trên cùng từ cột A sang cột B
  + Chuyển đĩa n-1 đĩa trên cùng từ cột C sang cột B ---> (2): Cột hiện tại: C, Cột đích: B, Cột trung gian: A 
## Cách thực hiện bước (1),(2) tổng quát
  + Chuyển n-2 đĩa trên cùng của cột hiện tại sang cột trung gian
  + Chuyển đĩa thứ n-1 từ cột hiện tại sang cột đích
  + Chuyễn n-2 đĩa từ cột trung gian sang cột đích
  + Tiếp tục gọi đệ quy cho các bài toán nhỏ hơn

# Thực hiện bằng code:
  + Yêu cầu: Trong mỗi lần đệ quy luôn phải cập nhật số lượng đĩa trên mỗi cột
  + Hàm Move(số lượng đĩa cần chuyển,cột hiện tại,số lượng đĩa cột hiện tại, cột đích,số lượng đĩa cột đích, cột trung gian,số lượng đĩa trung gian)
  + Cách execute:
    - Ban đầu cột A có n đĩa, nhưng trong mảng chạy từ 0 nên num_A=n-1;
    - num_B,num_C cần bắt đầu với 0
    - Chuyển n-1 đĩa trên cùng từ A sang C: move(n-1,A,num_A,C,num_C,B,num_B);
    - Chuyển đĩa thứ n sang cột B: Lúc này cột A mất đi 1 đĩa => numA--, cột B thêm 1 đĩa => numB++;
    - Chuyển đĩa n-1 đĩa trên cùng từ cột C sang cột B: move(n-1,C,num_C,B,num_B,A,num_A);
